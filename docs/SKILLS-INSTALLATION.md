# Skills 安装命令契约

本文面向 HoHu CLI 贡献者。用户安装步骤统一维护在 [HoHu Skills 安装指南](https://hohu.org/zh/guide/cli/skills)，本页解释包装层与验证边界。

## 当前行为

`hohu skills install` 调用固定版本 `skills@1.7.0`，来源固定为 `aihohu/hohu-skills`。使用当前工作目录，不自动切换到父项目。上游负责 Agent 发现、安装位置、交互、锁文件及覆盖行为；本命令不自行复制 Skill 或维护第二份安装状态。

| 参数 | 行为 |
| --- | --- |
| `--agent` / `-a` | 可重复，传递 Agent 标识；具体支持列表由固定版本上游决定 |
| `--global` / `-g` | 选择用户范围 |
| `--yes` / `-y` | 确认 npm 包下载及上游安装，必须同时指定至少一个 Agent |

需要稳定版 Node.js >=22.20.0，以及 PATH 中的 npm/npx。`--help` 不检查或下载依赖。Python 辅助检查脚本的 Python 3.12 要求属于 Skill 运行环境，CLI 自身继续支持其声明的 Python 版本。

进程继承标准输入输出、环境和当前目录，不捕获交互输出。POSIX 使用已解析的 npx；Windows 使用 Node.js 直接运行 npm 的 `npx-cli.js`，避免命令解释器重解析参数。非标准 Windows shim 无法找到入口时明确报错，并给出直接 npx 命令，不退回 shell 拼接。

保留上游非零退出码，信号退出归一为 `128 + signal`，包装层 Ctrl+C 返回 130，依赖或启动错误返回 1，参数错误返回 2。上游取消可能返回 0，因此包装层不额外输出“安装成功”。

## 验证与升级

新增行为回归见 [test_skills.py](../tests/test_skills.py)。CI 执行全量 CLI 测试，并对 Skills 安装与项目创建命令模块设置至少 70% 的合并覆盖率门禁；该数字不是整个 CLI 的总覆盖率。

更新安装器版本时重新检查 Node engines、Agent 参数、重复安装、锁文件、Windows 入口和交互取消。真实安装用隔离目录，本地源码验收与正式远程仓库验收分别记录。用户全局安装不能作为测试目录。

## 决策

1. **复用上游安装器** — 保持 npx 与 HoHu CLI 使用相同安装状态和 Agent 适配。**反例**: 单独维护目录映射与更新逻辑。**回归**: 多 Agent 参数测试及隔离安装检查。
2. **固定安装器版本** — 避免上游 latest 变化自动改变 CLI 行为；Skill 内容版本独立于安装器版本。**反例**: 宣称固定安装器即固定 Skill 源码。**回归**: 固定包参数测试和文档评审。
3. **保留上游覆盖语义** — 不向用户承诺额外的定制保护。**反例**: 添加 `--yes` 后仍以为旧目录不会被覆盖。**回归**: 重复安装验证，用户手册说明先备份定制。
